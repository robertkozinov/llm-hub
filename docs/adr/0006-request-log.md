# 6. Журнал запросов

Статус: Принято · 2026-11-23

## Решение
На каждый запрос пишется: модель, провайдер, программа (пароль), токены, стоимость в USD (считается в момент запроса), задержка до первого кусочка и общая, код ответа, ошибка. **Текст сообщений не хранится.** Есть сводка по моделям, провайдерам и программам за период.

## Последствия
- Нужны новые поля REQUEST_LOG — см. ADR 8.

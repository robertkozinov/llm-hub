# 5. Справочник моделей

Статус: Принято · 2026-11-23

## Контекст
Списки моделей провайдеров почти не содержат цен и возможностей; вести свой справочник вручную нереально.

## Решение
- Вшитая копия https://models.dev/api.json (MIT) с возможностью обновления. Из неё берутся тип и модальности, `limit.context`, `limit.output`, цены, `tool_call`, `reasoning`, `attachment`, признак устаревшей модели.
- Для Ollama данные берутся из `/api/show`.
- Модели, которых нет в справочнике, тоже работают; их стоимость пустая, а не 0.
- После добавления ключа список моделей провайдера заполняется автоматически; всё не для чата отсеивается по справочнику, запасной вариант — по имени.

## Последствия
- Работает офлайн; лицензию и источник указать в README и отчёте.

# 8. Схема БД и миграции

Статус: Предложено Робертом, ждёт ответа Артёма · 2026-11-23

## Контекст
Схему БД проектировал Артём (рисунок 4 отчёта), а применяет её ядро при старте. Для паролей шлюза, справочника моделей и журнала схемы с рисунка не хватает.

## Решение
**Миграции** — SQL-файлы goose в `core/`. Первая создаёт всю схему с рисунка 4 как есть, следующие добавляют изменения ниже. Позже миграции можно перенести.

**Изменения схемы:**
- новая таблица паролей шлюза; REQUEST_LOG получает ссылку на неё, поле `client` остаётся текстом;
- MODEL: тип, цены, возможности, deprecated, «избранное»;
- уникальность `model_name` — по паре `(provider_id, model_name)` вместо глобальной;
- REQUEST_LOG: стоимость, две задержки, ошибка.

**Экран выбора модели** использует новые поля: раздел «избранное», устаревшие модели свёрнуты.

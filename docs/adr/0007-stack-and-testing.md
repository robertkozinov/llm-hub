# 7. Библиотеки и тестирование ядра

Статус: Принято · 2026-11-23

## Решение
**Библиотеки** — других без нового ADR не добавляем:
- HTTP — стандартный `net/http` (маршруты Go 1.22+);
- SQLite — `modernc.org/sqlite` (без cgo);
- миграции — goose, SQL-файлы вшиты через `embed`, применяются при старте;
- CLI — Cobra; Keychain — go-keyring.

**Тесты:**
- тест пишется до кода;
- golden files — записанные ответы провайдеров, флаг `-update`;
- полный шлюз + поддельный провайдер на `httptest`;
- неприятные случаи отдельно: обрыв потока, 429/500, tool call по кусочкам, клиент отключился, нет usage;
- настоящая временная SQLite;
- живые тесты по тегу `live` проверяют устройство ответа, а не текст;
- CI — GitHub Actions.

# 1. Ядро — отдельный процесс `llmhub serve`

Статус: Принято · 2026-11-23

## Контекст
В отчёте этапа 2 ядро работает внутри процесса Wails и вызывается из интерфейса напрямую. Но шлюзом должны пользоваться и сторонние программы, и CLI, и веб-интерфейс, в том числе когда окно десктопа закрыто.

## Решение
Ядро всегда запускается как `llmhub serve`. Десктоп, веб, CLI и сторонние программы — клиенты по HTTP. Команды CLI при незапущенном шлюзе выводят подсказку и сами его не запускают.

## Последствия
- Один путь кода для всех клиентов, журнал видит все запросы.
- Расходится с отчётом — описать в финальном отчёте.
- Десктоп при открытии сам запускает `serve`, если он не запущен, и не гасит его при закрытии (делает Артём в GUI).
- Переключателя «разрешить сторонним программам пользоваться шлюзом» нет: доступ к шлюзу управляется паролями (ADR 4).

# 4. Ключи провайдеров и пароли шлюза

Статус: Принято · 2026-11-23

## Решение
**Ключи провайдеров** хранятся в Keychain через go-keyring за интерфейсом `SecretStore{Set,Get,Delete}` (в тестах — реализация в памяти). При добавлении ключ проверяется запросом списка моделей. В памяти ядра ключи кэшируются.

**Пароли шлюза:** у каждой программы свой (`llmhub tokens add|list|remove`). В БД хранится хеш, сам пароль показывается один раз. Наш CLI получает служебный пароль автоматически.

**Временно**, пока нет Keychain и БД: ключи и пароль шлюза читаются из `config.json` в `~/Library/Application Support/LLM Hub` (права 0600, вне репозитория).

## Последствия
- Известное ограничение: на macOS go-keyring пишет записи от имени `/usr/bin/security`, поэтому другие программы пользователя, вероятно, могут прочитать ключ без запроса. Проверить на маке и честно описать в отчёте.
- Для паролей нужна новая таблица — см. ADR 8.

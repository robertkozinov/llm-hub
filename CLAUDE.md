# LLM Hub

Локальный аналог OpenRouter для macOS (потом Linux): один шлюз в формате OpenAI к облачным и локальным моделям, плюс MCP-инструменты, CLI и GUI. Курсовая на двоих.

## Кто за что отвечает
- `core/` — ядро-шлюз на Go и CLI `llmhub` (Роберт).
- `integrations/` — Python-сервис интеграций на 127.0.0.1:4100: Hugging Face, Ollama, MCP (Артём).
- `gui/` — GUI на React + Wails (Артём).

Части общаются только по HTTP. Ядро — отдельный процесс `llmhub serve` на 127.0.0.1:4000 (ADR 1, ещё на согласовании).

## Решения
Все архитектурные решения — в `docs/adr/`, оглавление — `docs/adr/README.md`. Прочитай его, прежде чем менять что-то, что касается больше одной части или устройства ядра. Решения со статусом «Предложено» ещё не согласованы — не полагайся на них. Новое решение — новый файл ADR, старые не переписываются.

## Общие правила
- Ключи провайдеров и текст сообщений пользователей никогда не попадают в логи и в БД.
- Все локальные сервисы слушают только 127.0.0.1.
- Тест пишется до кода.
